Patent & Publications

IN 202041052449 · PATENT NO: 510765 · ISSUED FEB 14, 2024 · INDIAN PATENT OFFICE
Intelligent Goods Anti-Tamper System Using Radio Frequency Identification and Machine Learning
Real-time goods integrity monitoring during transit using UHF RFID + Neural Network + Reinforcement Learning + GPS + Pressure Sensors. Filed through VIT's School of Electronics Engineering (SENSE) Research Patents program.

The system monitors goods in containers using UHF RFID transceiver modules collecting RSSI data for distance estimation. A Neural Network integrates RSSI readings with read-response time, read rate, and compensation factors for precise distance estimation. The container is divided into 4 quadrants, each with vibration sensors monitoring goods integrity. Passive RFID tags conserve power, activating only near the reader — triggered on vibrations or door openings.

Reinforcement learning maps packages to PIDs and product details. GPS provides real-time tracking while pressure sensors detect weight changes indicating tampering. The system compensates for movement and vibration. Surpasses existing solutions by providing real-time distance measurements and vibrational monitoring, reducing manual checks and enhancing package management efficiency. Alerts and data processed in cloud; optional humidity/temperature sensors available per customer requirements.
